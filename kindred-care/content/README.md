| File | What it is | Primary use |

| `Postnatal_Complications_Clinical_Reference.docx` | The ten complications of postnatal care, ordered by consequence not frequency. **Both are compilations and neither is a substitute for primary verification.** The MBS
document says so on its face. Any commercial claim built on an item number, fee or rule
must be verified against MBS Online at the time it is made, and any billing-model advice
to a customer requires professional input we do not have.
