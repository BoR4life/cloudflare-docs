# Bundle of Rays — brand kit

| File | What it is |
| --- | --- |
| [`BRAND.md`](./BRAND.md) | The guidelines. Colour, type, texture, logo use, XR notes. |
| [`tokens.css`](./tokens.css) | CSS custom properties, with a dark-ground inversion. |
| [`tokens.json`](./tokens.json) | The same values as design tokens, contrast ratios inline. |
| [`brand-kit.html`](./brand-kit.html) | The visual kit — self-contained, opens in any browser. |
| [`logo/`](./logo) | Primary mark by Jean Jullien. **Placeholder raster — see BRAND.md.** |

Status: **v0.1, working draft.** The palette is proposed and needs sign-off. The logo
is a 225 × 224 px web thumbnail and needs to be replaced with vector artwork from
Jean Jullien's studio before any print, signage, garment or XR-texture use.

Contrast ratios throughout were computed against WCAG 2.1, not estimated.
